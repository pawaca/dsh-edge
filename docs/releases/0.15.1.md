## dsh-edge 0.15.1

Hotfix for public webpage fetching in 0.15.0. The upstream Harness baseline remains 0.1.5-rc.2.

### Fixed

- **Web fetch**: remove a leftover native proxy lookup from the Workers transport patch. Public URL requests previously failed before network access with `WEB_PROVIDER_ERROR: ReferenceError: proxyRouteFor is not defined`. Both Direct and Dynamic Loader modes now use platform fetch as intended.
- **Regression coverage**: run the patched standalone provider through public HTML retrieval, same-origin redirects, blocked targets, cross-origin redirect rejection, and network failure handling during release verification. The provider itself is not mocked in these tests.

### Validation and upgrade

Both Worker modes passed local integration tests and real-model probes against example.com, Xinhua English, and Jiemian News, returning HTTP 200 and rendered page content. Private-target restrictions and redirect policy are unchanged. A dependency audit found no other unresolved references caused by retained patches.

Upgrade with `npx dsh-edge@latest upgrade` after this version is published. This hotfix introduces no new storage schema or migration.
