## dsh-edge 0.22.0-alpha.1

Brings back the two plugin settings cards the Web client lost in 0.19, makes goals run reliably, and adds upstream's `/compact`, `/goal`, `present`, and session statistics. Published to npm's `next` channel; `latest` remains on 0.21.0. The upstream Harness baseline stays 0.2.0-rc.2 and the session format stays V4, so upgrading from 0.21 migrates no stored data.

### Fixed

- **Goal rounds** (#280): every automatic goal round now runs inside an Edge turn, with its workspace, the 10-minute turn deadline, Stop, and live progress in the Web client.
  - Before, a round started after the turn that created the goal had ended. The rounds of a goal the agent created ran outside the turn and its live view.
  - A goal started or resumed outside a turn failed at once with "File operations are only available during an active turn". That covers the GoalBar **Resume** button.
  - Stop, or the turn deadline, now also stops the goal, as upstream does. A round that was running is cancelled and the goal is paused. Between rounds, no further round starts. Either way **Resume** continues it.

### Added

- **Plugin settings cards** (#278): Settings → Built-in plugins gains a **Settings** tab next to the plugin list. It shows upstream's cards unchanged:
  - **Agent loop**: how many parallel-safe tool calls run at once within one step (default 10).
  - **Web search**: API key, endpoint, and how many searches one request may make (default 5).

  A saved value applies to the running instance without a restart. A saved endpoint must pass the same check as `DEEPSEEK_SEARCH_BASE_URL`, so an endpoint with credentials or a query is refused. On start, a value an earlier card saved that no longer passes is dropped and the deployment default applies, instead of the instance failing to start.
- **`/compact`** (#279): compacts the session's older history now, the same way automatic compaction does when the context fills, and reports how many history items it replaced. A command may now run for as long as a turn (10 minutes) instead of 30 seconds, because the summary is a model request.
- **`/goal`** (#280): shows, sets, edits, pauses, resumes, or clears the session's goal. `/goal <objective>` starts working on it at once.
- **Session statistics** (#281): the chat view shows whole-session turn and step counts and model throughput, from upstream's `sessionStats` projection. It is stored with the session's other cached values, so it adds no storage reads.
- **Deliverables** (#282): the agent can declare finished files with upstream's `present` tool, and each appears as a file card below the reply with a sidebar preview. The Edge has no desktop, so the card says files cannot open in external apps.

### Known limitations

- Upstream's turn outline (each turn's prompt and response preview) is not offered: it grows with every turn, and the Edge stores a session's cached values as one record, so a long session would outgrow it.
- Upstream's `/feedback` command is not offered: it keeps an anonymous user id in a local file, which Workers cannot store.
- Subagents cannot yet be messaged, interrupted, or listed while they run (upstream's `send_message`, `interrupt_agent`, and `list_agents`).
- `glob` and `grep` do not apply `.gitignore` files, so `grep` searches ignored files that ripgrep would skip.
- File write protection covers the `write` and `edit` tools. A shell or container command that writes a file during a guarded write is not detected, as in upstream; one that finished before the guarded write is.
- Rolling back to 0.18 after an upgrade from it is not supported.
- The Agent presets page intro and mode guide mention upstream's Creator mode, which the Edge does not offer.
- The 0.18.0 limitations about the Node 22 test environment, local `dev:container` cleanup, and symlinks outside `/workspace` still hold.

### Validation and upgrade

`pnpm run check` passes 889 tests. Integration runs against both release artifacts (Direct and Isolated), with new checks for:
- the settings namespaces and saves;
- `/compact` on fresh and real history;
- `sessionStats` after two turns;
- a `present` call with the Edge's Host desktop answers;
- goal rounds:
  - a goal the model creates runs its round inside the turn;
  - goals created over the API (on a warm agent and after a restart) and with `/goal <objective>` run their `bash` and `write` successfully;
  - Stop during a round leaves the goal paused.

Browser snapshots pin the Settings tab with both cards and a presented file card. The packed installer passes `pack:verify`. `upgrade-from-release.probe.mjs` upgrades state created by the published 0.21.0 and by the published 0.18.0, passing 11 checks each. Not yet validated on a staging instance.

Upgrade a test instance with `npx dsh-edge@next upgrade` and choose "Update it".
