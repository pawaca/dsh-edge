## dsh-edge 0.15.0-alpha.1

Harness 0.1.5-rc.2 适配的首个预览版。发布至 npm 的 `next` 频道；`latest` 保持为 0.14.1。建议先在测试实例试用，再升级主要部署。

### 变更

- **上游基线** (#173)：将已发布的 Harness 包固定到 0.1.5-rc.2，并适配上游 `SessionHandle` 持久化约定。已有会话格式在打开时通过上游格式目录迁移；V3 在规范消息事件内部保存聚合的 assistant 流。
- **浏览器文件预览** (#177)：将上游 `workspaceFiles` 控制器接入 Edge VFS，为新版右侧栏预览提供有界文本和字节读取，以及元数据订阅。经 owner 鉴权的下载功能继续可用。

### 修复

- **冷会话消息投递** (#177)：在选择模型前持久化初始化事件，确保后续 prompt 事件序号连续，并在完成持久化后到达 mux WebSocket。
- **中断会话恢复** (#177)：在上游恢复流程补齐结束事件前截断可修复的物理坏尾，并根据保留的事件前缀原子重建提醒状态和物化摘要。对于含有 inbox 回执或不安全提醒事件的尾部，拒绝自动修复，避免消息丢失或重复投递。
- **预览读取错误** (#177)：在打开和读取文件流时保留类型化文件系统错误与取消原因；清理失败不会覆盖原始错误。

### 验证

- 恢复了 prompt、fork、vision、queue/steer、文件引用、浏览器和定时任务覆盖。本地检查通过 405 个测试，保留两个原有旧格式迁移测试跳过项；6 个浏览器测试全部通过。
- 两种已提升的 Worker 产物均通过集成测试。真实 DeepSeek V4 Flash probe 验证了回复、文件工具读取，以及本地 Worker 重启后的上下文续聊。
- 审计了此前的批处理修复 (#170)。两种模式下，104 个 chunk 的回复均使用 9 次持久化批次、16 条会话事件行，其中 assistant 消息仅占一行。回归检查同时约束批次数并验证聚合流存储；这些数字不代表 Cloudflare 总计费行数。

真实 Cloudflare 测试实例上的持续运行和存储用量观察，仍是正式发布 0.15.0 前的 alpha 验证内容。
