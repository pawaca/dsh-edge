## dsh-edge 0.5.1-alpha.2

Fixes session title generation not appearing in the UI.

### Fixed

- **Late session event broadcasting**: async cordis plugins (session title, compaction) fire events after the turn-scoped observer disconnects. Added a persistent `session/event` observer that flushes and broadcasts events arriving outside an active turn, matching upstream's connection-scoped observer pattern.

### Root cause

Upstream runs as a long-lived Node process where sessions stay alive indefinitely. Edge's Durable Object disposes the turn observer when the turn completes. The session title plugin's auxiliary LLM call returns after disposal, so the title event was persisted but never broadcast to the WebSocket client.
