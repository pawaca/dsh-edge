## dsh-edge 0.32.0

用 `write` 或 `edit` 改过文件的回合下方，现在会显示 Web 客户端的变更文件卡片：列出每个文件增删的行数，并可在侧边栏打开对比。系统提示也加入了上游关于如何链接文件、何时使用 `present` 的说明。发布到稳定的 npm `latest` 渠道，代码与 [0.32.0-alpha.1](0.32.0-alpha.1.zh.md) 相同，后者已在 staging 上验证（见下文）。上游基线仍为 0.2.1-rc.2，会话格式仍为 V4。

### 新增

- **变更文件卡片**（#391）：Edge 现在按上游文档中的无 git 模式提供上游的 `workspaceChanges`（`dsh-workspace-changes`）。
  - **列出什么：**每个顶层回合中的 `write` 和 `edit` 调用。每个被编辑的文件会在本回合第一次编辑前和回合结束时各复制一份，按上游的方式逐行比较，并以 `workspace/changes` 事件公布。
  - **不列出什么：**Workers 不运行 git，所以只通过 `bash` 或在 Linux 容器中改动的文件不会列出，子代理会话也不记录。
  - **上限：**
    - 与上游一致，超过 2 MiB 的文件列出但不计行数、不提供对比；
    - 与上游不同，任一侧超过 20,000 行的文件也一样，因为比较会按行分配内存；
    - 含 NUL 字节的文件列为二进制；
    - 内容未变的重写不列出；
    - 一份摘要最多 500 个文件。
  - **副本存放：**副本存入工作区 VFS 的 `/.dsh/workspace-changes`，以 SHA-1 命名，因此一个回合在内存中最多同时保留两份文件内容。副本随会话删除，上一次 Durable Object 激活留下的副本会在下一次捕获前删除。
  - **保留期限：**与上游一致，摘要随常驻会话保留；重启后，之前的回合不再有卡片。

### 变更

- **交付物 Host 半边**（#391）：现在原样挂载上游 `dsh-client-ui-deliverables` 的 Host 半边。它提供卡片使用的 `/api/present.*` 和 `/api/changes.*` 路由，取代 Edge 自己的 present 处理器，在没有桌面时的回应与之前相同。它还在系统提示中加入上游的 `ui:deliverable-file-references` 段落：把提到的每个已有文件链接到其路径，主要结果在回复中直接展示，文件卡片有帮助时使用 `present`。Edge 之前没有发送这一段，所以模型的回复可能会更多地链接文件。

### 已知限制

- 变更文件卡片只列出文件工具的编辑；shell 和 Linux 容器中的编辑需要回合开始时的工作区视图，目前尚未实现。
- 编辑文件的回合会因副本多写一些 Durable Object 行：一个 `write` 新建了一个文件的回合比 0.31.0 多写 31 行。不编辑文件的回合不变。
- 0.31.0 列出的其他限制仍然适用。

### 验证

`pnpm run check` 通过 1,129 项测试。新增测试覆盖比较（行数、缺少结尾换行、超时后的整份替换）和记录器：
- 编辑、新建和删除的文件，内容未变的重写，工作目录之外和 `/tmp` 下的路径；
- 按字节和按行数判定的过大文件，以及二进制文件；
- 没有改动的回合和子代理不产生事件；
- 每份内容只复制一次；
- 删除已释放会话的副本，以及上一次激活留下的副本。

集成测试针对两种发布产物（Direct 和 Isolated）运行。一个脚本化的回合读取一个文件并编辑它、写一个新文件、用相同内容重写第三个文件，并通过 bash 改动第四个文件。
- `/api/changes.summary` 恰好列出被编辑的文件和新文件及其行数。
- `/api/changes.diff` 返回它们的 hunk。
- 交付物路由由上游的处理器应答。

新增的浏览器检查在两种模式下发送这个回合，找到 "Edited 2 files" 卡片，并打开一个文件的对比。

在 Workers 运行时中本地测得：
- `row-cost.probe.mjs` 对比 0.31.0：普通、bash 和定时回合写入的行数相同（九个普通回合共 443 行 SQL、36 次 KV 与 alarm 写入）。被唤醒的父会话写了一个文件的那一步多写 31 行（243 行，0.31.0 为 212 行），冷恢复读取 628 行，0.31.0 为 616 行。
- `upgrade-from-release.probe.mjs` 升级由已发布的 0.31.0 创建的状态，通过 11 项检查。

发布产物仍在 Cloudflare 的 64 MiB 大小限制内（Direct 8.4 MB，Isolated 9.7 MB）。

在从 0.31.0 升级到 0.32.0-alpha.1 的 staging 实例上（Isolated，带 Linux Container，PTC 模式），一个 DeepSeek-V4.1-Flash 回合读取并编辑了一个文件、写了一个新文件，并通过 bash 改动了第三个文件：
- 回复下方显示 "Edited 2 files" 卡片（+3 −1）：被编辑的文件 +1 −1，新文件 +2；
- 只通过 bash 改动的文件没有列出；
- 被编辑文件的对比可以在侧边栏打开；
- 文件工具是在 `run_code` 调用中运行的，卡片同样覆盖；
- 升级前的 53 个会话仍在列表中。

用 `npx dsh-edge@latest upgrade` 升级并选择"Update it"，然后刷新页面。网页会立即更新，但升级后的几分钟内，背后的实例可能仍在运行上一个版本。
