## dsh-edge 0.12.0-alpha.2

### Fixed

- **Installer login fails with "whoami --profile" error**: the post-login account verification called `wrangler whoami --json --profile dsh-edge-install`, but Wrangler rejects `--profile` on the `whoami` command. The installer now binds the profile to a throwaway directory via `auth activate` and reads accounts through `--cwd` instead, with a `realpath` canonicalization step so the stored binding key matches `process.cwd()` after chdir on macOS.
