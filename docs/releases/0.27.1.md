## dsh-edge 0.27.1

Adds the Web app's way to download a session log, missing from 0.27.0. Published to the stable npm `latest` channel. The upstream Harness baseline stays 0.2.1-rc.2 and the session format stays V4, so upgrading from 0.27.0 or 0.26 migrates no stored data.

### Fixed

- **Session log download in the Web app** (#332): 0.27.0 served session log downloads, but its Web app left out the part of upstream's `dsh-session-log-export` that runs in the browser. The session header had no More actions button with "Download session log", and `/export` started no download, so the download was reachable only through `/api/session.export`. Both now download the session's ZIP.

### Validation and upgrade

`pnpm run check` passes 979 tests. A new browser test in real Chromium, run against both release artifacts (Direct and Isolated), downloads a session's log from the header menu and with `/export` and reads the session's prompt out of each ZIP. `upgrade-from-release.probe.mjs` upgrades state created by the published 0.27.0, passing 11 checks.

Upgrade with `npx dsh-edge@latest upgrade` and choose "Update it", then reload the page. The Web page updates at once, but the instance behind it can keep running the previous version for a few minutes after an upgrade.
