## dsh-edge 0.15.0-alpha.1

First preview of the Harness 0.1.5-rc.2 integration. Published to npm's `next` channel; `latest` remains on 0.14.1. Use this alpha on a test instance before upgrading a primary deployment.

### Changed

- **Upstream baseline** (#173): pin the published Harness packages to 0.1.5-rc.2 and adapt persistence to the upstream `SessionHandle` contract. Existing session formats migrate through the upstream format catalog when opened; V3 stores compact assistant streams inside canonical message events.
- **Browser file previews** (#177): compose the upstream `workspaceFiles` controller over the Edge VFS for the new right-sidebar preview, with bounded text and byte reads and metadata subscriptions. Owner-authenticated downloads remain available.

### Fixed

- **Cold-session prompt delivery** (#177): persist initialization events before model selection so subsequent prompt events retain continuous sequence numbers and reach the mux WebSocket after durable storage.
- **Interrupted-session recovery** (#177): truncate repairable torn physical tails before upstream resume appends closing events, and rebuild reminder state and materialized summaries atomically from the retained prefix. Tails containing inbox receipts or unsafe reminder events are refused rather than risking lost prompts or duplicate delivery.
- **Preview read failures** (#177): preserve typed filesystem errors and cancellation across stream opening and consumption; cleanup failures cannot hide the original error.

### Validation

- Restored prompt, fork, vision, queue/steer, file-reference, browser and schedule coverage. Local checks passed with 405 tests and two pre-existing legacy migration skips; all six browser tests passed.
- Both promoted Worker modes passed integration tests. Real DeepSeek V4 Flash probes verified replies, file-tool reads and context continuation after a local Worker restart.
- Audited the earlier batching fix (#170). A 104-chunk response used 9 persistence batches and 16 session event rows in both modes, including one assistant message row. Regression checks bound batch count as well as verifying compact-stream storage; these figures are not total Cloudflare billed row counts.

Sustained operation and storage usage on a real Cloudflare test instance remain part of alpha evaluation before the stable 0.15.0 release.
