# dsh-edge 0.4.1

[English](https://github.com/pawaca/dsh-edge/blob/dsh-edge-v0.4.1/docs/releases/0.4.1.md) | 中文

Preset 投影和 URL 清理修复的补丁版本。

## 修复

- **实时 Preset 投影**：Agent Presets → View: DSH Edge 对话框现在从运行时 settings section 读取 `baseURL`、`reasoningEffort` 和 `maxTokens`，而非静态部署默认值。凭证状态实时解析。
- **URL 清理**：Preset 投影在渲染 settings 来源的 `baseURL` 前，会去除 query、fragment、用户名和密码，与部署配置已有的浏览器投影安全措施一致。

## 升级

```sh
npx dsh-edge upgrade
```

现有部署完全向下兼容，无需迁移。
