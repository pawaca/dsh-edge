# dsh-edge 0.4.1

English | [中文](https://github.com/pawaca/dsh-edge/blob/dsh-edge-v0.4.1/docs/releases/0.4.1.zh.md)

Patch release with preset projection and URL sanitization fixes.

## Fixes

- **Live preset projection**: The Agent Presets → View: DSH Edge dialog now reads `baseURL`, `reasoningEffort`, and `maxTokens` from the runtime settings section instead of static deployment defaults. Credential state is resolved live.
- **URL sanitization**: The preset projection strips query, fragment, username, and password from the settings-sourced `baseURL` before rendering, matching the deployment profile's existing browser-projection safeguard.

## Upgrade

```sh
npx dsh-edge upgrade
```

Existing deployments are fully backward compatible. No migration is required.
