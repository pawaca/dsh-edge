## dsh-edge 0.27.1

补上 0.27.0 中缺失的 Web 应用会话日志下载入口。本版发布至稳定的 npm `latest` 频道。上游 Harness 基线仍为 0.2.1-rc.2，会话格式仍为 V4，所以从 0.27.0 或 0.26 升级不会迁移任何已存数据。

### 修复

- **Web 应用中的会话日志下载**（#332）：0.27.0 已经能提供会话日志下载，但其 Web 应用漏掉了上游 `dsh-session-log-export` 在浏览器中运行的部分。会话标题栏没有带“Download session log”的 More actions 按钮，`/export` 也不会开始下载，所以只能通过 `/api/session.export` 下载。现在两者都会下载会话的 ZIP。同一个菜单还提供 Feedback，用于打开会话反馈对话框。

### 验证与升级

`pnpm run check` 通过 979 个测试。新增一个在真实 Chromium 中运行的浏览器测试，针对两种发布产物（Direct 和 Isolated），分别从标题栏菜单和用 `/export` 下载会话日志，并从每个 ZIP 中读出该会话的提问。`upgrade-from-release.probe.mjs` 原地升级由已发布的 0.27.0 创建的状态，通过 11 项检查。

使用 `npx dsh-edge@latest upgrade` 升级，选择“Update it”，然后刷新页面。Web 页面会立即更新，但其后的实例在升级后的几分钟内可能仍运行旧版本。
