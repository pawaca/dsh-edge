## dsh-edge 0.5.3

### 修复

- **Durable Object 行读取**：将 `SESSION_SUMMARY_SELECT` 中的 7 个关联子查询替换为物化 `dsh_session_summaries` 表，每次 `listApiSessions()` 调用的行读取量降低约 700 倍。修复了会话积累后出现的 "Exceeded allowed rows read in Durable Objects free tier" 问题。
- **空白会话提升**：`materializeBlankSession` 现在在同一事务中插入空日志摘要行，防止提升后的会话在下一次 append 之前从列表/获取 API 中消失。

### 技术细节

- 新 `dsh_session_summaries` 表使用 `CREATE TABLE IF NOT EXISTS` 创建；`DO_SESSION_SCHEMA_VERSION` 保持为 2，完全向下兼容。
- `syncSummaries()` 在 DO 初始化时运行，通过按会话重算来回填缺失或过期的行（revision 不匹配）。
- `appendBatch()` 和 `commitRepair()` 在现有事务内原子性地维护摘要行。
