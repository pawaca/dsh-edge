# dsh-edge 0.5.0

English | [中文](https://github.com/pawaca/dsh-edge/blob/dsh-edge-v0.5.0/docs/releases/0.5.0.zh.md)

Upstream baseline upgrade to 0.1.1-rc.2 with DeepSeek Files API support and Cloudflare Images optimization.

## Highlights

- **Upstream baseline rc.2**: All 28 `@deepseek-ai/*` dependencies upgraded from 0.1.1-rc.1 to 0.1.1-rc.2.
- **DeepSeek Files API**: Images are uploaded as reusable file-ids instead of inline base64, reducing request payload size. File-id mappings are cached in Durable Object KV via `DurableObjectUploadIndex`.
- **Cloudflare Images optimization**: When an `IMAGES` binding is configured, images are resized to the model's pixel budget before upload. Falls back to passthrough when unavailable. Free plan includes 5,000 unique transforms/month.
- **Patches reduced**: 2 of 5 patches adopted upstream (host-apiproxy Web Crypto, client-ui-workspace conditional delete). 1 new patch added for Files API `resolveFiles` slot.

## Upgrade

```sh
npx dsh-edge upgrade
```

### Optional: Enable image optimization

Add the Images binding to your `wrangler.jsonc`:

```jsonc
{
  "images": {
    "binding": "IMAGES"
  }
}
```

Existing deployments are fully backward compatible. No migration is required.
