# dsh-edge 0.5.0

[English](https://github.com/pawaca/dsh-edge/blob/dsh-edge-v0.5.0/docs/releases/0.5.0.md) | 中文

上游基线升级至 0.1.1-rc.2，支持 DeepSeek Files API 和 Cloudflare Images 优化。

## 亮点

- **上游基线 rc.2**：全部 28 个 `@deepseek-ai/*` 依赖从 0.1.1-rc.1 升级至 0.1.1-rc.2。
- **DeepSeek Files API**：图片上传为可复用的 file-id，替代内联 base64，减小请求 payload。file-id 映射通过 `DurableObjectUploadIndex` 缓存在 Durable Object KV 中。
- **Cloudflare Images 优化**：配置 `IMAGES` binding 后，图片在上传前会按模型像素预算自动缩放。未配置时静默降级为直通模式。免费套餐每月 5,000 次唯一变换。
- **Patch 数量减少**：5 个 patch 中 2 个被上游采纳（host-apiproxy Web Crypto、client-ui-workspace 条件删除），新增 1 个 Files API `resolveFiles` slot patch。

## 升级

```sh
npx dsh-edge upgrade
```

### 可选：启用图片优化

在 `wrangler.jsonc` 中添加 Images binding：

```jsonc
{
  "images": {
    "binding": "IMAGES"
  }
}
```

现有部署完全向下兼容，无需迁移。
