## dsh-edge 0.12.0-alpha.2

### 修复

- **安装器登录后 "whoami --profile" 报错**：登录后的账号验证调用了 `wrangler whoami --json --profile dsh-edge-install`，但 Wrangler 不支持在 `whoami` 命令上使用 `--profile`。安装器现改为通过 `auth activate` 将配置绑定到临时目录，并使用 `--cwd` 读取账号信息，同时通过 `realpath` 规范化路径以确保在 macOS 上 chdir 后存储的绑定键与 `process.cwd()` 匹配。
