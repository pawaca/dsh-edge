## dsh-edge 0.22.0-alpha.1

找回了 Web 客户端在 0.19 中失去的两张插件设置卡片，让目标可靠运行，并加入上游的 `/compact`、`/goal`、`present` 和会话统计。发布到 npm 的 `next` 渠道；`latest` 仍为 0.21.0。上游 Harness 基线仍为 0.2.0-rc.2，会话格式仍为 V4，所以从 0.21 升级不会迁移任何已存数据。

### 修复

- **目标轮次**（#280）：每一轮自动目标轮次现在都在 Edge 的 turn 内运行，带有工作区、10 分钟的 turn 时限、停止功能，并在 Web 客户端实时显示进度。
  - 以前，一轮在创建目标的那个 turn 结束之后才开始。agent 创建的目标，其轮次在 turn 及其实时视图之外运行。
  - 在 turn 之外设定或恢复的目标会立即失败，报错"File operations are only available during an active turn"。GoalBar 的 **恢复** 按钮就属于这种情况。
  - 停止或到达 turn 时限时，现在也会停止目标，与上游一致：正在运行的轮次会被取消，目标随之暂停；在两轮之间则不会再开始新的一轮。两种情况下点 **恢复** 都能继续。

### 新增

- **插件设置卡片**（#278）："设置 → 内置插件"在插件列表旁新增 **设置** 标签页，原样显示上游的卡片：
  - **Agent 循环**：同一步内最多同时运行多少个可并行的工具调用（默认 10）。
  - **网页搜索**：API key、接口地址，以及一次请求最多搜索几次（默认 5）。

  保存的值无需重启即对运行中的实例生效。保存的接口地址必须通过与 `DEEPSEEK_SEARCH_BASE_URL` 相同的校验，所以带凭证或查询参数的地址会被拒绝。启动时，早期卡片保存、如今已无法通过校验的值会被丢弃并改用部署默认值，而不会让实例无法启动。
- **`/compact`**（#279）：立即压缩会话中较早的历史，方式与上下文将满时的自动压缩相同，并报告替换了多少条历史。由于摘要是一次模型请求，命令现在最长可运行与一个 turn 相同的时间（10 分钟），而不是 30 秒。
- **`/goal`**（#280）：查看、设定、编辑、暂停、恢复或清除会话的目标。`/goal <objective>` 设定后立即开始工作。
- **会话统计**（#281）：聊天视图显示整个会话的 turn 数、step 数和模型吞吐量，数据来自上游的 `sessionStats` projection。它与会话的其他缓存值存放在一起，不增加存储读取。
- **交付物**（#282）：agent 可以用上游的 `present` 工具声明完成的文件，每个文件以卡片形式显示在回复下方，可在侧边栏预览。Edge 没有桌面，所以卡片会说明文件无法用外部程序打开。

### 已知限制

- 不提供上游的 turn 大纲（每个 turn 的提问与回答预览）：它随每个 turn 增长，而 Edge 把一个会话的缓存值存为一条记录，长会话会超出上限。
- 不提供上游的 `/feedback` 命令：它把匿名用户 id 保存在本地文件中，Workers 无法保存。
- 子 agent 运行期间暂时无法发消息、中断或列出（上游的 `send_message`、`interrupt_agent` 和 `list_agents`）。
- `glob` 和 `grep` 不应用 `.gitignore` 文件，所以 `grep` 会搜索 ripgrep 本会跳过的被忽略文件。
- 文件写入保护只覆盖 `write` 和 `edit` 工具。在受保护的写入进行期间，由 shell 或容器命令写入的文件改动不会被发现，这与上游一致；在受保护的写入之前已完成的改动会被发现。
- 从 0.18 升级后不支持退回 0.18。
- Agent 预设页的介绍和模式说明提到了上游的 Creator 模式，Edge 不提供该模式。
- 0.18.0 中关于 Node 22 测试环境、本地 `dev:container` 清理以及指向 `/workspace` 之外的符号链接的限制仍然存在。

### 验证与升级

`pnpm run check` 通过 889 个测试。集成测试覆盖两个发布产物（Direct 和 Isolated），新增的检查包括：
- 设置命名空间及其保存；
- 在新会话和真实历史上运行 `/compact`；
- 两个 turn 之后的 `sessionStats`；
- 一次 `present` 调用，以及 Edge 对 Host 桌面检查的回答；
- 目标轮次：
  - 模型创建的目标在 turn 内运行其轮次；
  - 通过 API 创建的目标（热 agent 和重启后）和用 `/goal <objective>` 设定的目标，其 `bash` 和 `write` 都运行成功；
  - 轮次进行中停止会让目标暂停。

浏览器快照固定了带两张卡片的设置标签页和一张交付物文件卡片。打包后的安装器通过 `pack:verify`。`upgrade-from-release.probe.mjs` 分别升级由已发布的 0.21.0 和 0.18.0 创建的数据，各通过 11 项检查。尚未在 staging 实例上验证。

用 `npx dsh-edge@next upgrade` 升级测试实例，选择"Update it"。
