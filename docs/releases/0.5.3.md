## dsh-edge 0.5.3

### Fixed

- **Durable Object row reads**: replaced 7 correlated subqueries in `SESSION_SUMMARY_SELECT` with a materialized `dsh_session_summaries` table, reducing row reads by ~700× per `listApiSessions()` call. Fixes "Exceeded allowed rows read in Durable Objects free tier" on instances with accumulated sessions.
- **Blank session promotion**: `materializeBlankSession` now inserts an empty-log summary row in the same transaction, preventing promoted sessions from disappearing from list/get APIs until the next append.

### Technical

- New `dsh_session_summaries` table created with `CREATE TABLE IF NOT EXISTS`; `DO_SESSION_SCHEMA_VERSION` stays at 2 for full backward compatibility.
- `syncSummaries()` runs on DO initialization, backfilling missing or stale rows (revision mismatch) using per-session recomputation.
- `appendBatch()` and `commitRepair()` maintain summary rows atomically within their existing transactions.
