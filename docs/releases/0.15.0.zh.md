## dsh-edge 0.15.0

将 0.15.0-alpha.2 的运行时提升至 npm `latest` 正式渠道。相对 alpha.2 没有运行时代码变更。上游 Harness 基线为 0.1.5-rc.2。

### 相对 0.14.1 的变化

- **Harness 集成**（#173）：采用上游 `SessionHandle` 持久化契约和 V3 会话格式，在规范消息事件中紧凑存储助手流。
- **文件预览**（#177）：通过 Edge VFS 支持右侧栏文件预览，提供有界读取和元数据订阅。所有者认证的下载仍然可用。

### 修复

- **会话投递与恢复**（#177）：在模型选择前持久化初始化事件，确保提示词送达冷启动会话；修复可安全处理的中断物理尾部，并原子重建提醒状态和摘要。拒绝不安全的尾部修复，以免丢失提示词或重复投递。
- **旧数据升级**（#179）：在 V0 迁移前规范化已知历史取消记录，在迁移写入前验证全部旧版本日志，并原子提交事件、会话头和摘要。
- **迁移写入量**（#179）：按预估行成本选择逐会话替换或紧凑事件表重建，限制事件读取量，避免逐会话执行策略查询。本地 workerd 样本实测写入为 1,934 行，优化前为 155,493 行，迁移后的事件内容一致；这不代表任意数据库的保证值或账户总使用量。
- **安装验证**（#179）：要求会话服务和 DeepSeek 适配器完成初始化，并核对本次上传的 Cloudflare Worker 版本后才报告成功。重试临时部署认证失败，并按 UTF-8 字节长度验证所有者密钥。
- **恢复访问与取消**（#179）：模型适配器初始化失败时保留会话和恢复路由，就绪检查报告失败。浏览器覆盖确认停止回复后恢复发送控件，且不显示 `[object Object]`。

### 验证与升级

Alpha.2 已通过 Linux 和 Windows CI、两种 Worker 模式的集成测试、六项浏览器测试和仓库外安装检查。本正式版沿用该运行时，仅变更发布身份和说明。

使用 `npx dsh-edge@latest upgrade` 升级。已有 alpha 部署应显式使用 `@latest` 切换至正式渠道。大型迁移前请检查剩余 Durable Objects 配额：事务回滚和数据库还原不会退回已消耗的配额。
