## dsh-edge 0.15.1

修复 0.15.0 的公开网页抓取问题。上游 Harness 基线仍为 0.1.5-rc.2。

### 修复

- **网页抓取**：移除 Workers 传输补丁中残留的原生代理查询。此前公开 URL 请求尚未访问网络就会报错 `WEB_PROVIDER_ERROR: ReferenceError: proxyRouteFor is not defined`。Direct 和 Dynamic Loader 两种模式现均按预期使用平台 fetch。
- **回归覆盖**：在发布验证中，让安装了补丁的独立装配 provider 实际执行公开 HTML 抓取、同源重定向、受限目标拦截、跨源重定向拒绝和网络错误处理。这些测试不模拟 provider 本身。

### 验证与升级

两种 Worker 模式均通过本地集成测试，并使用真实模型访问 example.com、新华社英文站和界面新闻，返回 HTTP 200 及转换后的网页正文。私网目标限制与重定向策略保持不变。依赖审计未发现其他由保留补丁导致的未定义引用。

此版本发布后，使用 `npx dsh-edge@latest upgrade` 升级。本次 hotfix 不引入新的存储结构或迁移。
