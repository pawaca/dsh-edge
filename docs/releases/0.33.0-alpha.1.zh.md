## dsh-edge 0.33.0-alpha.1

上游基线升级到 DeepSeek Harness 0.2.1-rc.3。DeepSeek provider 现在从 DeepSeek 官方的 `/models` 接口获取模型列表；会话标题栏的“更多”菜单让窄屏上被折叠的视图仍可打开。发布到 npm 的 `next` 渠道；`latest` 仍为 0.32.0。会话格式仍为 V4。

### 变更

- **上游基线 0.2.1-rc.3**（#394）：所有 `@deepseek-ai/dsh-*` 包从 0.2.1-rc.2 升级。多数包只改动了版本号。
- **官方模型列表：**使用内置模型目录和官方 API 地址时，DeepSeek provider 与上游自 rc.3 起一样，从 `GET /models` 获取模型列表。
  - Durable Object 启动后的第一次模型请求最多等待 5 秒。
  - 超过 10 分钟的列表会在后台刷新。
  - 获取失败时保留上一次成功的列表，或使用内置目录。
  - 自定义模型列表或使用其他地址时不发起请求。
  - Models 页面会显示两个新设置：`modelsTimeoutMs` 和 `modelsMaxAgeMs`。
  - 内置目录的上下文窗口改为 1,048,576 个 token（原为 1,000,000）。
- **“More conversation views”菜单：**rc.3 起，会话标题栏会把标签行放不下的视图收进一个“更多”菜单。上游通过 `dsh-client-ui-entry-customization` 填充这个菜单，以及左侧栏和右侧引导页新增的“更多”菜单。该包的“浏览其他插件”和“创建你的插件”需要 Edge 不提供的插件页面和 Creator 预设，所以没有打包。
  - Edge 改为在会话菜单中注册自己的一项，只列出被折叠的视图；所有视图都放得下时，菜单只显示一行不可点击的提示。
  - 侧边栏和引导页的“更多”菜单不显示。
- **其他上游改动：**切换会话后，“新会话”不再丢失未发送的草稿。

### 已知限制

- 左侧栏和右侧栏的“更多”菜单，以及从中浏览和创建插件，均不可用。
- 0.32.0 列出的其他限制仍然适用。

### 验证

`pnpm run check` 通过 1,129 项测试。所有 Edge 补丁都能重新应用，其中两个为 Worker 打包内联 Harness 版本号的补丁（`dsh-llm`、`dsh-repeat-tool-reminder`）现在写入 0.2.1-rc.3。上游参考表现在有 200 个条目，新包已归类。

集成测试针对两种发布产物（Direct 和 Isolated）运行，Linux Container 集成测试也通过。新增的浏览器检查在两种模式下把窗口缩到 320 像素：Trajectory 被收进“更多”，菜单恰好只列出这个视图、没有插件操作，选中后切换视图。回合快照只有目录的上下文窗口发生变化，浏览器快照新增了“More conversation views”按钮。

在 Workers 运行时中本地测得：
- `row-cost.probe.mjs` 对比 0.32.0：每一步写入和读取的行数都相同（九个普通回合共 443 行 SQL、36 次 KV 与 alarm 写入）。
- `upgrade-from-release.probe.mjs` 升级由已发布的 0.32.0 创建的状态，通过 11 项检查。

发布产物仍在 Cloudflare 的 64 MiB 大小限制内（Direct 8.4 MB，Isolated 9.8 MB）。尚未在 staging 实例上验证。

用 `npx dsh-edge@next upgrade` 升级测试实例，并选择"Update it"。
