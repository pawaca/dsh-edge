## dsh-edge 0.34.0

Moves the upstream baseline to DeepSeek Harness 0.2.1-rc.4, a fix-only release. Published to the stable npm `latest` channel, with the same code as [0.34.0-alpha.1](0.34.0-alpha.1.md), which passed a staging run (below). The session format stays V4.

### Changed

- **Upstream baseline 0.2.1-rc.4** (#397): every `@deepseek-ai/dsh-*` package moves from 0.2.1-rc.3. Most packages change only their version.
- **Conversation View tabs:** a tab shows its full-name tooltip only when its label is too long for the tab. The More conversation views button keeps its plain name and is highlighted when the active View is folded into it; the menu marks that View as current.
- **Not affecting the Edge:** upstream's other two fixes keep diagnostics off stdout in ACP mode, for the DeepSeek account provider and for MCP resource listing. The Edge signs in with an API key, and its own MCP client lists resources only on servers that declare them.

### Known limitations

The limitations listed for 0.33.0 still hold.

### Validation

`pnpm run check` passes 1,129 tests. Every Edge patch re-applies, and the two that inline the Harness version for the Worker bundle (`dsh-llm`, `dsh-repeat-tool-reminder`) now carry 0.2.1-rc.4. The upstream reference keeps its 200 entries.

Integration runs against both release artifacts (Direct and Isolated), and the Linux Container integration passes. Snapshots are unchanged. The narrow-window browser check now confirms the switch by the menu row marked as current, since the More button no longer names the active View.

Measured locally in the Workers runtime:
- `row-cost.probe.mjs` against 0.33.0: every step writes and reads the same rows (443 SQL rows and 36 KV and alarm writes over nine plain turns).
- `upgrade-from-release.probe.mjs` upgrades state created by the published 0.33.0, passing 11 checks.

On a staging instance upgraded from 0.33.0 to 0.34.0-alpha.1 (Isolated, with the Linux Container):
- readiness reported upstream 0.2.1-rc.4;
- the 54 sessions from before the upgrade were still listed;
- a DeepSeek-V4.1-Flash turn completed;
- the model catalog listed DeepSeek-V4.1-Flash and DeepSeek-V4-Pro with their reasoning levels;
- the More conversation views button kept its plain name, and with every View in the tab row its menu showed only "Every view is in the tab row".

Folding into More on a narrow window was checked by the browser test above rather than on staging.

Upgrade with `npx dsh-edge@latest upgrade` and choose "Update it", then reload the page. The Web page updates at once, but the instance behind it can keep running the previous version for a few minutes after an upgrade.
