## dsh-edge 0.31.0-alpha.1

命令退出后才到达的输出不再让 Linux Container 停止；删除的工作区文件会释放存储；过大、无法迁移的旧会话也不再让实例无法启动。发布到 npm 的 `next` 渠道；`latest` 仍为 0.30.0。上游基线仍为 0.2.1-rc.2，会话格式仍为 V4。工作区存储格式会在首次启动时升级，0.30 无法读取升级后的格式（见“升级”）。

### 修复

- **命令退出后到达的容器输出**（#373，#384）：Container 镜像改用 computerd 0.7.0，Worker 改用 `@cloudflare/computer` 0.7.0；两者是同一套通信协议，必须一起升级。命令退出后还有输出到达时，computerd 0.3.1 会停止，容器和其中的所有命令随之终止。用 `&` 启动的后台任务仍占着管道，或 Durable Object 读取比命令输出慢时，就会出现这种情况。
  - 现在命令在两个输出管道都关闭后结束。如果后台任务仍占着管道，则在 shell 退出 250 毫秒后结束；该任务之后写出的输出会被丢弃，容器继续运行。
  - 0.29.0 中“把大量输出重定向到文件”的绕过办法不再需要。
- **过大、无法迁移的旧会话**（#371，#387）：以 V4 之前格式存储的会话，会在升级后首次启动时转换。上游的转换器一次处理整份日志，内存占用约为存储大小的四倍（在 128 MiB 堆下实测：22 MiB 可以转换，26 MiB 内存耗尽）。
  - 事件数据超过 8 MiB 的会话现在保持原样，并在 Worker 日志中记录警告；以前它会让实例每次启动都失败。
  - Edge 把这样的会话视为不存在：它不出现在列表中，按 id 读取也会回答不存在。它存储的事件会保留。
  - 只有从 0.19.0（会话格式改为 V4 的版本）之前的版本升级、且仍保有这种会话的实例才会遇到。

### 变更

- **删除文件会释放存储**（#358，#386）：工作区把文件内容存为可共享的内容块，删除或覆盖文件从不删除这些块，所以存储只增不减。每日清扫现在也会删除没有任何文件使用的内容块，每次最多 200 个，且只删除闲置至少一天的块。
  - Linux Container 运行时跳过本次清理，因为容器可能正在同步尚未关联到文件的内容。
  - 只在它所针对的工作区存储版本上运行，遇到其他版本时会停止并记录警告。
  - 过期的 spill 文件、被替换的上传，以及模型删除或覆盖的文件都在此列。

### 已知限制

- Linux Container 仍使用 Computer 的平台调度后端（`LegacyContainerBackend`）。Computer 新的由 Durable Object 调度的后端需要新的 Durable Object 类，会把每个实例已存储的数据留在旧类中，因此要等 Cloudflare 支持转换现有应用后再迁移（#385）。
- 删除文件的存储要在最后一次使用一天以后才会释放；每次每日清扫最多 200 个内容块（未完成时每小时一次），且容器运行时不清理。
- 0.30.0 列出的其他限制仍然适用。

### 验证

`pnpm run check` 通过 1,123 项测试。新增测试覆盖：
- 内容块清理：基于已安装 Computer 自己的表定义，覆盖删除哪些块、一天的余量、跨次续扫，以及其他存储版本。另有测试锁定清理对 Computer 的假设，以后的升级若改变这些假设，CI 会失败。
- 8 MiB 迁移上限：实例正常启动，其他会话照常迁移，大会话不出现在列表中且行数据保留，也不会有表重建把它丢掉。

集成测试针对两种发布产物（Direct 和 Isolated）运行。Container 集成测试新增一项：让后台任务在 shell 退出后写出 200,000 行，确认同一个容器能继续执行下一条命令。这项检查在 0.30.0 上会失败。

在 Workers 运行时中本地测得：
- `row-cost.probe.mjs` 对比 0.30.0：普通回合写入的行数相同（九个回合共 443 行 SQL、36 次 KV 与 alarm 写入）。第一个回合读取 225 行，0.30.0 为 153 行；多出的 72 行是内容块清理每天一次的扫描，最多约 2,000 行。
- `vfs-reclaim.probe.mjs`，两种模式：删除一个 939 KB 的文件、并把它的内容块调到余量之前后，下一次清理恰好释放它的 938,890 字节，保留的文件能完整读回。
- `upgrade-from-release.probe.mjs` 升级由已发布的 0.30.0 创建的状态，通过 11 项检查，其中包括存储格式升级后读回工作区文件。

发布产物仍在 Cloudflare 的 64 MiB 大小限制内（Direct 8.4 MB，Isolated 9.7 MB）。尚未在 staging 实例上验证。

### 升级

用 `npx dsh-edge@next upgrade` 升级测试实例，并选择"Update it"。

**这次升级对工作区存储是单向的。** 首次启动时，Computer 0.7.0 会把工作区存储格式从版本 8 升到 10，而 0.30.0 会拒绝版本 10。运行过本版本的实例回滚到 0.30.0 后，将无法读取工作区文件。
