# dsh-edge 0.2.0-alpha.1

English | [中文](https://github.com/pawaca/dsh-edge/blob/dsh-edge-v0.2.0-alpha.1/docs/releases/0.2.0-alpha.1.zh.md)

This is the first prerelease of the standalone dsh-edge wrapper. It preserves the released 0.1.3 Cloudflare runtime and durable-data contracts while replacing the DeepSeek Harness source fork with an exact published-package assembly.

## Highlights

- Installs directly from npm without cloning a repository, connecting GitHub, or configuring Cloudflare Builds.
- Offers a Workers Free Direct Shell mode and an optional Workers Paid Dynamic Worker mode from one package.
- Runs the upstream DeepSeek Harness Web UI, agent loop, HTTP/WebSocket protocol, persistent sessions, workspace VFS, bash tool, and DeepSeek Web Search.
- Keeps the upstream Harness dependency closure pinned to `0.1.0-rc.7`, with six audited, version-bound assembly patches.
- Preserves the 0.1.3 Durable Object, session/event, workspace, and VFS formats.
- Adds an Edge settings page for installed version, npm update channel, release notes, upgrade guidance, runtime diagnostics, and owner-session management.

## Install or upgrade the prerelease

Requires Node.js 22.14 or newer and your own DeepSeek API key.

```sh
npx dsh-edge@next install
```

Existing 0.2 prerelease deployments follow the same channel:

```sh
npx dsh-edge@next upgrade
```

The stable `latest` channel remains on 0.1.3 during the alpha. Durable Object data is retained during an upgrade, but Cloudflare's write-only secrets require entering the existing owner access key and DeepSeek API key again.

## Current scope

The deployment is intentionally single-owner. Attachments and images, remote MCP, Skills, Workflows, Jobs, and Subagents are not yet adapted to the Edge runtime. `web_fetch` remains disabled until the runtime has an explicit policy for SSRF, private addresses, and redirects. Direct Shell is not a Linux container and must not be exposed to untrusted users.

## Release integrity

The npm package is published under the `next` dist-tag from the reviewed `dsh-edge-v0.2.0-alpha.1` tag. A manual request workflow forwards that tag to release automation anchored on the default branch; unreviewed tag revisions cannot replace the workflow that receives npm publishing authority. The release workflow rebuilds and verifies the pinned standalone assembly, both Worker modes, 0.1.3 durable-state compatibility, browser/runtime snapshots, and the installed tarball before publication. The matching GitHub prerelease carries that same tarball as an asset.
