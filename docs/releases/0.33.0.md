## dsh-edge 0.33.0

Moves the upstream baseline to DeepSeek Harness 0.2.1-rc.3. The DeepSeek provider now lists models from DeepSeek's official `/models` endpoint, and the Conversation header's More menu keeps folded Views reachable on a narrow screen. Published to the stable npm `latest` channel, with the same code as [0.33.0-alpha.1](0.33.0-alpha.1.md), which passed a staging run (below). The session format stays V4.

### Changed

- **Upstream baseline 0.2.1-rc.3** (#394): every `@deepseek-ai/dsh-*` package moves from 0.2.1-rc.2. Most packages change only their version.
- **Official model listing:** with the built-in model catalog and the official API base URL, the DeepSeek provider lists models from `GET /models`, as upstream does since rc.3.
  - The first model request after a Durable Object starts waits up to 5 seconds for the listing.
  - A listing older than 10 minutes refreshes in the background.
  - A failed listing keeps the last good one, or the built-in catalog.
  - A customized model list or another base URL requests nothing.
  - The Models page shows the two new settings, `modelsTimeoutMs` and `modelsMaxAgeMs`.
  - The built-in catalog's context window is now 1,048,576 tokens (was 1,000,000).
- **The More conversation views menu:** since rc.3 the Conversation header folds the Views that do not fit its tab row into a More menu. Upstream fills that menu, and new More menus in the left sidebar and the right-sidebar guide, from `dsh-client-ui-entry-customization`. That package's **Browse other plugins** and **Create your plugin** need the plugin page and the Creator preset, which the Edge does not offer, so it is not shipped.
  - The Edge registers its own row in the Conversation menu instead, listing only the folded Views; when every View fits, the menu shows a single inactive line.
  - The sidebar and guide More menus are not shown.
- **Other upstream changes:** New Session no longer loses an unsent draft after switching sessions.

### Known limitations

- The left-sidebar and right-sidebar More menus, and plugin browsing and creation from them, are not available.
- The other limitations listed for 0.32.0 still hold.

### Validation

`pnpm run check` passes 1,129 tests. Every Edge patch re-applies, and the two that inline the Harness version for the Worker bundle (`dsh-llm`, `dsh-repeat-tool-reminder`) now carry 0.2.1-rc.3. The upstream reference now lists 200 entries, and the new package is classified.

Integration runs against both release artifacts (Direct and Isolated), and the Linux Container integration passes. A new browser check, in both modes, narrows the window to 320 pixels: Trajectory folds into More, the menu lists exactly that View with no plugin actions, and choosing it switches the View. The turn snapshot changes only in the catalog's context window, and the browser snapshot gains the More conversation views button.

Measured locally in the Workers runtime:
- `row-cost.probe.mjs` against 0.32.0: every step writes and reads the same rows (443 SQL rows and 36 KV and alarm writes over nine plain turns).
- `upgrade-from-release.probe.mjs` upgrades state created by the published 0.32.0, passing 11 checks.

The release artifacts stay within Cloudflare's 64 MiB size limit (Direct 8.4 MB, Isolated 9.8 MB).

On a staging instance upgraded from 0.32.0 to 0.33.0-alpha.1 (Isolated, with the Linux Container):
- readiness reported upstream 0.2.1-rc.3;
- the 53 sessions from before the upgrade were still listed;
- a DeepSeek-V4.1-Flash turn completed;
- the model catalog listed DeepSeek-V4.1-Flash and DeepSeek-V4-Pro with their reasoning levels;
- the Conversation header's More menu was the Edge's own: with every View in the tab row, it showed only "Every view is in the tab row" and no plugin actions.

Folding into More on a narrow window was checked by the browser test above rather than on staging.

Upgrade with `npx dsh-edge@latest upgrade` and choose "Update it", then reload the page. The Web page updates at once, but the instance behind it can keep running the previous version for a few minutes after an upgrade.
