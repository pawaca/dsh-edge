## dsh-edge 0.6.0-alpha.8

Removes the boot-time repack migration; final alpha before 0.6.0 stable.

### Removed

- **Boot-time repack**: the `repackExistingChunks` migration ran on every DO cold start to compress legacy `assistant/chunk` rows. It caused data loss from partial commits and was only needed for pre-alpha.5 data. New writes are already packed via `appendBatch`; legacy sessions load fine with the raised `maxEvents` limit (65,536).
